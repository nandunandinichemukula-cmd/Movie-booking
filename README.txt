# MovieBook - BookMyShow Style JavaScript Project

Open index.html in a browser.

Features:
- Movie posters (local SVG posters)
- Search movies
- Theatre selection
- Show-time selection
- Interactive seat layout
- Booked/available/selected seats
- Customer details and payment method
- Booking summary
- Confirmation ticket with booking ID
- window.close() attempt after successful booking

Important:
Modern browsers normally block JavaScript from closing a tab that the user opened manually.
window.close() works reliably when the booking page/window was opened by JavaScript.
